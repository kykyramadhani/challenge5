# PlayFeat: Single-Player Rules

**Status:** Agreed settings for the first playtest. Balance still needs validation.

**Updated:** 21 October 2026

| Rule | Setting |
|---|---|
| Role selection | Play **one role per run**: Procurement, Chef, or Front House |
| Session duration | **Unlimited**. No rounds or level timer |
| Procurement order duration | **60 seconds per order** |
| Chef order duration | **60 seconds per order** |
| Front House order duration | **60 seconds per order** |
| Order timers | Start when each order appears and count down independently. Completing another order does not reset them |
| Maximum active orders | **3** |
| First order | Appears at **0 seconds**, when gameplay begins |
| Regular arrivals | The next order appears **20 seconds after the most recent arrival**, while space is available |
| Full queue | Stop the arrival countdown at **3 active orders**. Do not accumulate hidden orders |
| First slot opens after a full queue | Start a **fresh 20-second arrival countdown** |
| Additional slots open | Keep the existing countdown. **Do not reset or shorten it** |
| Queue becomes empty | Wait for the scheduled arrival. **Do not refill immediately** |
| Order priority | Players may choose **any active order** |
| Order completion | Complete all requirements for the **selected role only** |
| Starting hearts | **3 hearts** |
| Expired order | Remove the order and lose **1 heart** |
| Heart reset | No automatic reset during the run |
| Game over | End the run immediately at **0 hearts**. Stop all timers and arrivals |

## Scheduling Example

This is an illustrative timing example, not a playtest observation.

- The queue fills at second **40**.
- A slot opens at second **50**, so the next arrival is scheduled for second **70**.
- Another slot opens at second **55**, but the next arrival **stays at second 70**.
